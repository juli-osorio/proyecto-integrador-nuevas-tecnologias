# Taller Excel a PDF con Python

Juliana Osorio — Nuevas Tecnologías

Este script lee el archivo `ventas_tecnologia_v2.xlsx`, muestra los productos en consola con tabulate y genera un informe en PDF con ReportLab.

También incluye los retos: filtro de productos con precio mayor a $100, cálculo del total de unidades vendidas y precio promedio, búsqueda de productos por ID y un menú interactivo.

## Cómo ejecutarlo

```bash
pip install openpyxl tabulate reportlab
python Taller_Excel_PDF_JulianaOsorio.py
```

Los PDF generados y las capturas de pantalla de la consola están en este repositorio.
